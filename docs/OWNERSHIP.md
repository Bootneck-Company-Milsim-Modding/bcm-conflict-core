# Ownership, dependencies and excluded data

This is a private BCM source handoff under Bootneck-Company-Milsim-Modding. No open-source licence is granted and no additional redistribution rights are inferred. No contributors or third-party licences have been invented for this import.

The sole declared dependency is vanilla Arma Reforger data (58D0FB3206B6F859), supplied by each developer's legitimately installed game/server. The native metadata/source references are preserved; base-game archives, models, textures, audio, SDK/HTML documentation and executable binaries are not copied into this repository. The current 180-file Addon snapshot consists of native text project/script/resource/metadata files; no external purchased binary asset restoration is required for this snapshot. That does not grant rights to publish unrelated assets or another BCM repository's content.

Private profiles, account settings, backend session material, campaign saves/reset archives, test server configs, credentials, logs/dumps, generated resource databases and downloaded Workshop archives are intentionally not transferred. Original files remain on the original PC. Transfer needed campaign data separately and securely after stopping its owner; do not reconstruct it from Git.

Historical documentation and launchers retain old paths and fixture descriptions. They are evidence, not active server settings or safe-to-run deployment automation. Do not reintroduce excluded configs merely to make an old launcher work.

Publisher does not use Git's ignore rules. The Addon-only layout reduces accidental inclusion, but proof resources and any later generated/private files still need explicit package inspection. Never publish the repository root as an addon root.
